# TicTacToe Minimal API

Простий пет-проєкт для гри в хрестики-нулики проти бота. 

### Як це працює
* **Бекенд:** C# (ASP.NET Core Minimal API) — генерує сесії гри та обробляє ходи гравця і бота.
* **Фронтенд:** Чистий JavaScript, HTML та CSS — робить запити на бек і малює дошку.

### Як запустити
1. Запустити C# бекенд через `dotnet run`.
2. Відкрити `index.html` у браузері.
